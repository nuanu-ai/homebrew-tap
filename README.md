# Nuanu AI Homebrew Tap

Install Agent Payment Node on Apple Silicon macOS:

```sh
brew install nuanu-ai/tap/apn
```

The Formula uses the immutable APN `v0.2.5` GitHub release asset and its
checked SHA-256 digest. It installs `node@24` as a Homebrew dependency and
leaves wallet/operation state under `~/.apn` across reinstall and upgrade.

Source and security model: <https://github.com/nuanu-ai/agent-payment-node>
